# Báo cáo ngày – SE Tân Châu (T03)

Trang web cá nhân của Nguyễn Duy Khánh (SE, VFC – Tân Châu, An Giang) để nhập và báo cáo doanh số hằng ngày, tháng 10/2026.

## Các tab
- **Kế hoạch**: kế hoạch từng ngày theo tuyến, mỗi dòng 1 đại lý – 1 sản phẩm (nạp sẵn từ file KHDS tháng 10: 357 dòng, 406 thùng, 2.764.290.442 đ).
- **Thực hiện**: nhập số bán theo đại lý, sản phẩm, số thùng; tự lưu.
- **Báo cáo Ngày**: mẫu "VFC – Mục tiêu và kết quả ngày Territory", tự tính từ Kế hoạch và Thực hiện, xuất file Excel đúng mẫu (`Khánh_Báo cáo ngày_dd.mm.yyyy.xlsx`).

## Dùng
Mở `index.html` (hoặc bật GitHub Pages cho repo này). Không cần cài đặt hay build.

## Lưu dữ liệu
- Mặc định lưu trên trình duyệt của từng máy.
- Điền cấu hình Firebase (Firestore) trong `config.js` để điện thoại và máy tính dùng chung số liệu.

Xem thêm `HUONG_DAN.txt`.
